# MVP 验收测试计划

本文件是 [技术方案](../TECHNICAL_PLAN.md) 对应的行为验收用例。当前仅编写用例，以下功能尚未实现，所有用例状态均为“待执行”；不得将文档检查通过解释为 App 或采集验收通过。

## 自动化集成测试

使用真实临时 SQLite 和文件目录；时间由可控时钟推进，测试不实际等待 5 天。网络失败可在外部请求边界注入，不替换待验证的数据库和文件保存行为。

| 编号 | 输入与操作 | 期望结果 |
| --- | --- | --- |
| A01 | 一个消息含文字和两张不同图片，执行采集 | 原图可打开、缩略图可用，两张图关联同一消息且保留文字 |
| A02 | 保存后让原临时地址失效，再打开图片 | 仍能读取持久副本，不能依赖原地址 |
| A03 | 同一事件重复投递，并重启后再次投递 | 消息、出现记录、文件数量不重复，有效期不延长 |
| A04 | 两个群分别发送内容相同但 URL 不同的文件 | 只保存一份原图，保留两个来源；改变文件内容后不误合并 |
| A05 | 下载超时、半途断开、成功恢复后重试 | 失败可见、不显示已保存；重试后只出现一个完整副本，临时文件最终回收 |
| A06 | 下载执行中终止 worker 后重启 | 超时租约可回收、任务继续，既不永久卡住也不重复创建来源 |
| A07 | 添加中文两字标签、备注和伴随文字，并搜索及组合筛选 | 结果符合文字和来源/日期/收藏条件；含 `%`、`_` 的查询按字面匹配 |
| A08 | 普通记录推进到接收后 119:59:59、120:00:00，并执行清理 | 前者可访问，后者不可访问；清理后原图及缩略图释放，接口无失效条目 |
| A09 | 图在第 1 天和第 4 天各出现一次，第 6 天和第 9 天执行清理 | 第 6 天只保留第二条有效来源及共享文件；第 9 天无有效来源后回收 |
| A10 | 收藏后推进至第 10 天，随后取消收藏并清理 | 收藏时图片及来源保留；取消时提示过期，确认后可清理，不重置接收时间 |
| A11 | 清理与收藏/同图新消息并发，文件删除失败后再次清理 | 成功收藏或新有效引用的文件不被误删；回收状态拒绝收藏并说明；删除失败可恢复且不虚报空间 |
| A12 | 缩短/延长保留天数；对已过期任务请求重试 | 按原接收时间重新计算；收藏豁免；过期普通任务不再下载 |
| A13 | 设置较低容量预算并模拟磁盘写满 | 清理到期内容后仍不足则暂停下载、状态明确；不丢失未过期图片或收藏，恢复空间后可重试 |
| A14 | 未登录、会话过期、退出登录后请求列表/原图/缩略图 | 均拒绝访问；有效会话能读取，媒体目录无绕过鉴权入口 |
| A15 | 下载地址指向内网、实例元数据或重定向到这些地址；提供越界路径、超大文件 | 请求被拒绝，不能读取敏感地址或覆盖任意文件；无“已保存”假状态 |
| A16 | 暂停/移除来源、重复事件、过期旧事件 | 不再创建该来源的新下载，已有数据仍按保留规则处理；不复活重复来源 |
| A17 | 原图落盘后、数据库提交前中断；以及已保存文件被移走 | 重启后孤立/缺失文件被发现，状态修复，无永久虚假成功 |
| A18 | 一条普通消息过期且文件和正文均清理后，重启并再次投递同一事件 | 去重凭据阻止再次下载及延长有效期，旧内容不复活；真正的新消息可正常采集 |

## Android 与云端实际验收

| 编号 | 操作 | 期望结果与证据 |
| --- | --- | --- |
| R01 | 云端真实账号接入测试群，发送普通单图、多图、混合消息，测试断线重连 | 核对实际可接收范围、来源字段与落盘文件；记录账号、接入版本及脱敏结果 |
| R02 | 安装 APK、配置 HTTPS 地址并登录，浏览、筛选、收藏、编辑后重启 App | 编辑持久保存，界面正常；截图及操作记录，不含凭据 |
| R03 | 长列表滚动、大图缩放、弱网/断网再恢复 | 无崩溃或无限加载，失败可恢复，内存占用可接受；记录设备与版本 |
| R04 | 保存相册和分享，分别拒绝/允许权限并模拟设备空间不足 | 成功结果可由系统相册/分享目标读取，失败明确且权限不过度 |
| R05 | 填满缓存预算、清理缓存、服务器图片过期后再联网 | 缓存受限且能清理；同步移除过期缓存；主动保存的相册副本仍在 |
| R06 | 手机关机，在群发送新图，随后开机打开 App | 新图已由云端保存，手机后台没有承担采集职责 |
| R07 | 使用同一签名的新版 APK 覆盖旧版 | 可成功升级，登录设置按设计保留；签名密钥不在仓库 |
| R08 | 重启服务器、模拟 QQ 登录失效、关闭清理后恢复 | 持久数据仍在、异常可见，恢复后补做清理；不保证漏收期间回填 |
| R09 | 从独立备份恢复收藏图片和数据库 | 收藏及来源可读取；先清理过期普通内容再开放访问，不产生空壳图片 |
| R10 | 少量真实群连续运行一周 | 抽查单图/多图、重复、断线及磁盘变化，记录缺失和失败；无未解释异常后再扩展 |
